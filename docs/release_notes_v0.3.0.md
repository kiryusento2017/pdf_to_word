## 详细说明

上一个正式版是 **v0.2.6**。

### 1. 下好的 GPU 运行库装不上

下载完 2.5 GB，界面说「重启后生效」，重启之后版本一点没变，再点检查又
要重下一遍。

下载和安装本身都是好的，缺的是中间那一下——软件重启后没有人去问「有没有
下好等着装的」，也没有任何地方去点那个「装」。

现在下载完当场就出现「立即重启」按钮，点一下装完自动重启，一步到位。

### 2. 转换历史打开永远是空的

开机去取历史的时候，服务还没准备好，那次请求必然失败，而失败被悄悄咽掉
了，界面上什么都不说。

### 3. 进度条涨满又清零

原来那条进度显示的是「当前这一步」的比例，而一份 PDF 要走七步，所以你会
看到它涨满、归零、再涨满，来回好几次。

现在按各步骤实际耗时的占比算，**只往前不往后**，真转完之前最多停在 99%。

### 4. Word 里夹着看不懂的字母

识别引擎会把图片里认出来的文字单独存一份，转 Word 时这部分本该丢掉，
结果标签丢了、文字留下了。11 份讲义里出现 1053 处。

### 5. 转换历史（新）

底部状态栏多了个「历史」，转换过程中也能点。每转完一份就记一条，
**关掉软件也还在**，留最近 200 条。

每一行能做三件事：打开转好的 Word、打开它所在的文件夹、鼠标停上去看当时
的完整报错。转失败的那行，「文件夹」打开的是**源 PDF** 所在的位置，
想重转直接从那儿拖回来。

### 6. 转换报告（新）

全部转成功时不出现。有转失败的、有扫描页、有公式没转成的时候，底下才多
一个「看报告」按钮，点开能看能复制。

### 另外几处

**倒计时越用越准。** 每台电脑显卡快慢不一样，软件会拿你自己转过的真实
耗时去校准，用着用着就准了。

**识别过程分两轮显示**：「逐页识别 23/56 页」和「识别公式和文字
544/1100 项」，点文件那一行能展开看走到哪一步了。

**清理那一屏多了两项**：「下好的升级包」和「升级备份」。以前它们混在
「转换临时文件」里，点一次清理会把刚下好的 2.5 GB 一起删掉；升级备份更是
一次占 4 GB，装完也不会自己消失，而界面上根本看不见它。

**老显卡不会再装到跑不了的运行库。** 原来只看驱动版本挑，1080Ti 这类卡
可能挑到一个装得上、却跑不起来的版本。

### 两件事先说在前面

**加载识别模型那几十秒，进度条是不动的。** 那一段引擎不吐任何进度，没法
显示真实百分比。阶段名会写着「正在加载识别模型」，不是卡死了。

**已经装好的 GPU 运行库不会自动换版本。** 环境检测页会提示可以升级，
你点了才动；不点也能照常转换。
